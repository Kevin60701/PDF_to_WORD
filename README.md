# PDF 轉 Word 小工具

此倉庫目前放置的是 **2026/10/16 19:08 快照**。專案以瀏覽器讀取 PDF，產生可下載的 Word `.docx` 檔案，提供版面精確、原生段落與圖片三種轉換模式。

## 快速開始

1. 將 `index.html`、`style.css` 和 `app.js` 放在同一個資料夾。
2. 使用新版 Chrome 或 Edge 開啟 `index.html`。
3. 選取或拖曳 PDF，選擇轉換模式後按「開始轉換」。
4. 完成後下載產生的 `.docx` 檔案。

程式庫由 CDN 載入，因此使用時需要網路連線。

## 轉換模式

| 模式 | 編輯方式 | 版面處理 |
| --- | --- | --- |
| 版面精確（文字可編輯） | PDF 文字放入可編輯的 Word 文字框 | 依 PDF 座標定位，頁面背景圖保留其他視覺內容 |
| 原生段落 | 一般 Word 段落，可編輯及自動換行 | 依文字位置估算縮排與段距，可設定保留換行及頁面分隔 |
| 圖片模式 | 頁面文字不可編輯 | 每頁轉為圖片插入 Word |

原生段落模式會嘗試將 `(1)`、`(2)` 等項目辨認為 Word 自動編號。這項辨認依文字格式規則處理，其他編號形式可能不會辨認。

## 功能

- 支援 PDF 檔案選取及拖放。
- 顯示檔案資訊、轉換進度、錯誤訊息和文字預覽。
- 以原 PDF 檔名產生 `.docx` 下載檔案。
- 使用 PDF.js 讀取 PDF，以 docx 套件建立 Word 文件。
- PDF.js、worker 與 docx 程式庫設有 CDN 備援來源。

## 隱私與限制

PDF 在瀏覽器中讀取及處理；此工具沒有將 PDF 上傳至自有伺服器的流程。載入 CDN 程式庫需要網路連線。

本工具不含 OCR。掃描 PDF 若沒有文字層，請選擇圖片模式。PDF 與 Word 的排版機制不同，原生段落模式不保證與 PDF 像素級一致；多欄、表格、公式、複雜圖文混排及特殊字型可能需要手動修整。精確模式的背景圖內容也不會成為可單獨編輯的 Word 物件。

## 檔案
