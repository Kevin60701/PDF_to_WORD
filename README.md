# PDF 轉 Word 小工具

這是一個純前端的 PDF 轉 Word 網頁工具。使用者在瀏覽器選取 PDF 後，可選擇版面精確、原生段落或圖片模式，產生可下載的 `.docx` 檔案。

## 快速開始

1. 確認 `index.html`、`style.css` 與 `app.js` 放在同一資料夾。
2. 使用最新版 Chrome 或 Edge 開啟 `index.html`。
3. 拖曳 PDF 到選擇區，或點擊選擇 PDF。
4. 選擇轉換模式並設定需要的選項。
5. 按「開始轉換」，完成後按下載連結取得 Word 檔。

工具使用 CDN 載入 PDF.js 與 docx.js，因此使用時需要網路連線。若瀏覽器直接開啟本機 HTML 時無法載入套件，請改用 Chrome／Edge，或將 HTML 放到可存取的靜態網站空間。

## 轉換模式

| 模式 | 文字編輯 | 版面方式 | 適用情境 |
| --- | --- | --- | --- |
| 版面精確（文字可編輯） | 可選取及修改文字框中的文字 | 每行文字放入依 PDF 座標定位的 Word 文字框；頁面背景圖保留非文字視覺內容 | 版面外觀優先，接受文字不會像一般段落流動 |
| 原生段落 | 一般 Word 段落，可重排及自動換行 | 依文字、縮排、段落間距和圖片重建頁面內容 | 希望以一般段落方式編輯文字 |
| 圖片模式 | 不可編輯文字 | 每頁轉成圖片放入 Word | 掃描檔或重視頁面外觀的文件 |

原生段落模式提供兩個選項：

- **保留 PDF 原本的換行**：每個擷取到的文字行分成獨立 Word 段落。關閉時會依行距、題號等線索合併續行，讓文字能以一般段落重新排版。預設關閉。
- **在每頁之間插入分頁**：預設開啟，讓 PDF 各頁在 Word 中從新頁開始。

原生段落模式會嘗試把 `(1)`、`(2)` 等項目轉成 Word 自動編號，讓清單可繼續編號。此判斷依文字格式啟發式處理，其他編號格式未必能自動辨認。

## 功能

- 接受 `.pdf` 檔案，支援拖曳及檔案選擇。
- 顯示檔名、檔案大小、轉換進度、錯誤或警告訊息。
- 轉換完成後提供瀏覽器下載連結；輸出檔名沿用 PDF 名稱並改為 `.docx`。
- 原生段落模式會擷取頁面文字與可辨識的內嵌影像，並在頁面之間安排分頁。
- 版面精確模式會保留文字字型、大小、粗體、斜體、顏色及底線等可擷取資訊；頁面其他視覺內容以背景圖保留。
- 圖片模式會逐頁將 PDF 畫成圖片並放入 Word。
- 轉換完成後在網頁列出前幾段文字預覽。

## 資料與隱私

本工具沒有自建上傳服務。PDF 由瀏覽器讀取並交給 PDF.js 處理，Word 檔也在瀏覽器中產生；頁面會從 CDN 載入 PDF.js 與 docx.js 等轉換程式庫。工具程式未實作將 PDF 內容傳送至應用程式伺服器的流程。

## 技術組成

- HTML（`index.html`）、CSS（`style.css`）、原生 JavaScript（`app.js`）
- PDF.js `3.11.174`：讀取 PDF 文字、頁面與影像運算子，並繪製頁面
- `docx` `8.5.0`：建立 Word 文件、段落、編號及圖片
- PDF.js worker 與兩個程式庫均設有多個 CDN 備援來源

## 限制

- 不含 OCR。若 PDF 是掃描圖片且沒有文字層，原生段落模式會提示改用圖片模式。
- 密碼保護或損毀的 PDF 可能無法處理。
- PDF 與 Word 的字型、字型替代、分頁和行距規則不同；原生段落模式不保證像素級一致。
- 原生段落模式不是完整的 PDF 版面解析器；多欄、表格、複雜圖文混排、公式、旋轉文字及向量線條可能需要人工修整。
- 精確模式中的文字框可編輯，但表格線、圖形及其他背景視覺內容不是 Word 原生物件。
- 圖片模式只保留外觀，頁面文字無法搜尋或編輯。
- 依瀏覽器安全設定、網路、防火牆或內容攔截器，CDN 程式庫可能無法載入。
- PDF 頁數或圖片解析度較高時，瀏覽器可能需要較多記憶體；目前沒有設定檔案大小上限。
